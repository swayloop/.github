## Standards & Tooling

org 차원의 워크플로우, 이슈 관리, 코딩 표준은 [`.github`](https://github.com/swayloop/.github) 레포에서 관리합니다.

- [.github](https://github.com/swayloop/.github) — 공통 표준 메타 레포 (workflows, 이슈/PR 템플릿, labels, docs, agent skills)
- [template-node](https://github.com/swayloop/template-node) — Node 프로젝트 부트스트랩 템플릿 (husky + commitlint + release-please + reusable workflows)
- [standards](https://github.com/swayloop/standards) — 공유 설정(tsconfig/eslint/prettier)을 프로젝트에 적용하는 CLI
- [tsconfig-base](https://github.com/swayloop/tsconfig-base) — `@swayloop/tsconfig-base`
- [eslint-config](https://github.com/swayloop/eslint-config) — `@swayloop/eslint-config`
- [prettier-config](https://github.com/swayloop/prettier-config) — `@swayloop/prettier-config`
- [commitlint-config](https://github.com/swayloop/commitlint-config) — `@swayloop/commitlint-config`
