# 예시

DayDot 레포에서 `/pm-discovery`(Codex: `$pm-discovery`) 실행 — 한 바퀴.

## 1. 맥락 로드

`references/project-context.md` 를 읽는다:

> 목적: DayDot = 일기 웹앱. north star = 자기이해 컨텐츠로 유입 → 일기 습관 전환.
> 현재: 로그인 후 일기/감정 기록 동작. 공개 유입 경로 없음.
> 인사이트: 사람들은 일기를 "작심삼일"로 포기 — 진입장벽이 문제(리뷰 근거).
> 로그: (아직 없음)

## 2. 가설 설정 (사용자와 합의)

> 가설: **"로그인 전 공개 '자기이해 설문' 페이지가 있으면, 방문자의 일기 시작 전환이 생긴다."**

## 3. 기능 결정 (최소)

> 최소 기능: `/self-understanding` 공개 페이지 — 5문항 객관식 → 결과 1개 → "오늘 일기 시작" CTA. (로그인 불필요)
> 우선순위: 이거 하나만. 결과 로직·디자인은 v0 수준.

## 4. 이슈 생성 (create-issue 위임)

`create-issue` 스킬을 호출해 DayDot 레포에 이슈 생성. 본문에 가설+성공지표 포함:

> 가설: 공개 설문 → 일기 시작 전환
> 성공지표: 설문 완료율, 완료→일기시작 클릭률
> 결과: `#123 feat: 자기이해 설문 공개 페이지 (v0)` 생성됨.
